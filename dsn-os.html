1. System Overview

DSN OS is designed as a Progressive Web Application (PWA) that provides a desktop-like environment within a web browser. It integrates with local device storage and supported cloud storage services through browser-based storage APIs and the File System Access API.

ប្រព័ន្ធនេះត្រូវបានរចនាឡើងដើម្បីផ្តល់បទពិសោធន៍ ប្រើប្រាស់ស្រដៀងនឹង Desktop OS ប៉ុន្តែដំណើរការនៅក្នុង Browser។

2. System Components

Module Description
Kernel (Core) Handles resource management, application state persistence, and communication between system components.
File System (VFS) Provides a Virtual File System abstraction for browser storage and supported local file-system integrations.
Display Engine Manages visual settings such as brightness, contrast, themes, and dark mode through CSS Custom Properties and browser styling APIs.
App Store Manages the discovery and installation of web-based applications within the DSN OS environment.

3. Implementation Guidelines

Storage Integration

The following example demonstrates the basic concept of selecting a local directory and creating an application file. 

// Example: Local File System Integration

async function installAppToLocalFolder(appManifest) {
    const directoryHandle =
        await window.showDirectoryPicker();

    const appFile =
        await directoryHandle.getFileHandle(
            appManifest.name,
            { create: true }
        );

    // Write application data to the selected file.
}

⚠️ Note: The File System Access API is supported only in compatible browsers and may require user permission.

Display & Brightness Control

Display brightness can be adjusted by applying a CSS filter to the root document element: 

document.documentElement.style.filter =
    `brightness(${value}%)`;

Theme Management

DSN OS can store the selected theme in localStorage and restore it automatically when the application starts. 

// Save the selected theme
localStorage.setItem('dsn_theme', 'theme-matrix');

// Restore the saved theme
const savedTheme =
    localStorage.getItem('dsn_theme');

if (savedTheme) {
    document.body.className = savedTheme;
}

Home Page Customization

The home page can use a JSON-based configuration stored in localStorage to manage pinned applications, shortcuts, and widget layouts. 

// Example: Home Page Configuration

const homeConfig = {
    pinnedApps: [
        "appstore",
        "music",
        "library"
    ],
    theme: "theme-matrix"
};

localStorage.setItem(
    'dsn_home_config',
    JSON.stringify(homeConfig)
);

4. Integration Architecture

The overall DSN OS architecture can be organized into several logical layers:

Layer Role
User Interface Provides the visual interface, navigation, dashboards, and interactive controls.
Application Layer Runs individual DSN OS applications and tools.
System Services Handles themes, storage, settings, notifications, and shared application state.
Browser APIs Provides access to supported browser capabilities such as storage, audio, files, and device features.

5. Security & Permissions

DSN OS runs inside the browser security model. Access to local files, folders, microphone, camera, notifications, or other protected resources requires appropriate browser permissions.

🔐 Users should review browser permission prompts carefully before granting access to sensitive resources.

6. Future Integration

Future versions of DSN OS can extend the architecture with authentication, cloud synchronization, application versioning, offline caching, service workers, and additional Progressive Web App capabilities.
